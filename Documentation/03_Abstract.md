# ABSTRACT

Community support systems play a crucial role in connecting donors with individuals in need, particularly in developing countries where social safety nets may be limited. This project presents the design and implementation of NawiriKe CRM, a web-based Community Support Management System developed to streamline the process of donation management, victim registration, and fund distribution within communities in Kenya.

The current manual processes for managing community support initiatives are characterized by inefficiencies, lack of transparency, and difficulties in tracking donations and their impact. These challenges often lead to reduced donor confidence and inefficient resource allocation. The proposed system addresses these issues by providing a centralized platform that automates donation processing, victim application management, and fund distribution tracking.

The system was developed using PHP for server-side scripting, MySQL for database management, and modern web technologies including HTML5, CSS3, and JavaScript for the front-end interface. The development followed a structured methodology encompassing requirement specification, system analysis, design, implementation, and testing phases.

Key features of the NawiriKe CRM include user role-based access (donors, victims, administrators), secure donation processing via M-Pesa integration, real-time tracking of donations and distributions, comprehensive reporting capabilities, and a user-friendly interface designed to enhance user experience. The system also incorporates robust security measures to protect sensitive user information and ensure transaction integrity.

Testing of the system was conducted using both functional and non-functional testing approaches, including unit testing, integration testing, and user acceptance testing. The results demonstrated that the system meets the specified requirements and provides an efficient, transparent, and user-friendly solution for community support management.

The successful implementation of NawiriKe CRM demonstrates the potential of technology to enhance community support initiatives by improving transparency, efficiency, and accountability in donation management. This system can serve as a model for similar initiatives in other communities and regions facing similar challenges in community support coordination.
