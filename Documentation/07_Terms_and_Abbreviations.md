# TERMS AND ABBREVIATIONS

**API** - Application Programming Interface  
**CRM** - Customer Relationship Management  
**CSS** - Cascading Style Sheets  
**DBMS** - Database Management System  
**DFD** - Data Flow Diagram  
**ERD** - Entity Relationship Diagram  
**HTML** - HyperText Markup Language  
**HTTP** - HyperText Transfer Protocol  
**HTTPS** - HyperText Transfer Protocol Secure  
**JS** - JavaScript  
**JSON** - JavaScript Object Notation  
**M-Pesa** - Mobile Money Transfer Service in Kenya  
**MySQL** - My Structured Query Language  
**NF** - Normal Form  
**OOSAD** - Object-Oriented Systems Analysis and Design  
**PHP** - Hypertext Preprocessor  
**SSAD** - Structured Systems Analysis and Design  
**UI** - User Interface  
**UX** - User Experience  
**URL** - Uniform Resource Locator  
**WAMP** - Windows, Apache, MySQL, PHP  
**XAMPP** - Cross-Platform Apache, MySQL, PHP, Perl  

**System-Specific Terms:**

**Admin Dashboard** - Administrative interface for managing the entire system  
**Donor Dashboard** - User interface for donors to manage donations and view history  
**Victim Dashboard** - User interface for victims to view received donations and status  
**General Pool** - Collective fund for general distribution to approved victims  
**Distribution** - Process of allocating funds from the general pool to specific victims  
**Victim Application** - Request submitted by individuals seeking assistance  
**Donation Type** - Classification of donation (direct to victim or general pool)
